My ongoing **Data Structures & Algorithms** practice in plain JavaScript — organised topic by topic, with the questions kept alongside my solutions so each folder can be revised on its own.

No frameworks, no libraries. Every file runs with `node`.

---

## 📚 Topics

| Folder | What's inside |
|--------|---------------|
| [Beginner_Array](./Beginner_Array) | 21 core array problems — max/min, second largest, reversal, rotation, duplicates, missing number, majority element, union & intersection, subarrays |
| [Intermediate_Array](./Intermediate_Array) | Harder array work — digit reduction, valid walk, triangle validation |
| [Strings](./Strings) | 14 string problems — reversal, palindromes, vowel/consonant counts, anagrams, first non-repeating character, frequency maps |
| [Sorting](./Sorting) | Sorting algorithms and related practice questions |
| [Recursion](./Recursion) | Recursion fundamentals and worked examples |
| [Loops](./Loops) | Loop basics and iteration drills |
| [Conditionals](./Conditionals) | Logic problems — Armstrong numbers, palindromes, grade assignment, electricity bill, INR cash counter, vowel/consonant checks |
| [Patterns](./Patterns) | 10 pattern-printing programs — pyramids, diamonds, butterfly, hollow square, zig-zag, number patterns |

Most topic folders keep a `Questions.js` next to an `Answers.js`, so you can attempt a problem before reading the solution.

---

## ▶️ Running a Solution

```bash
git clone https://github.com/sachin-codes01/DSA-PRACTICE.git
cd DSA-PRACTICE
node Beginner_Array/01_max_and_min.js
```

Any file can be run the same way — just point `node` at its path.

## 🎯 Purpose

This repo is a study log, not a library. It tracks how I'm working through DSA fundamentals in JavaScript: writing the brute-force answer first, then tightening it. New topics get added as I reach them.
